# Pixabay Photo Preview App
Pixabay API를 사용해 사진을 보여주는 간단한 앱

## 요구 사항
- 검색 기능
  - 검색하고 사진을 검색(tag)
  - 연타 방지
- 디테일 기능
  - 사진에 대한 자세한 정보를 출력

[Pixabay API](https://pixabay.com/api/docs/)
